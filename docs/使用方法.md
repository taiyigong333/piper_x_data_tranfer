# Piper-X 转 DynamicVLA

## 依赖

```bash
cd code
UV_CACHE_DIR=/tmp/uv-cache uv sync
```

## 转换

```bash
UV_CACHE_DIR=/tmp/uv-cache uv run python -m piperx_to_dynamic_vla.convert \
  --input /home/cv/gcj/data_collect/data/rotating_red_square_blue_plate \
  --output /home/cv/gcj/project/data_transfer/to_dynamic_vla/after_transfer \
  --fps 30
```

转换器只扫描 `batch_*/<collection>/forward/*_trajectory.hdf5`，不会读取 `reverse`。图像从采集的 640x480 RGB JPEG 解码，保持宽高比缩放后补黑边到 384x384。状态使用 HDF5 中已经与相机帧对齐的 `*_align` 序列；每条输出 episode 的 parquet 与视频严格保持相同帧数，训练 fps 固定为 30。

输出是 LeRobot v2.1 目录：`data/` 保存 parquet，`videos/` 保存两路 MP4，`meta/` 保存 info、stats、tasks 和 episodes 元数据。
